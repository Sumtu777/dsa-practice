# dsa-practice

Data structures and algorithms practice in Python, working towards coding interviews. Every problem is logged, including the ones I couldn't solve alone.

## Method

1. Attempt each problem for 25 minutes.
2. If stuck, study a solution, close it, and rewrite it from memory.
3. Re-solve it 2–3 days later.

## Structure

One folder per pattern, one file per problem, e.g. `arrays-hashing/two_sum.py`.

## Patterns

- [ ] Arrays and hashing
- [ ] Two pointers
- [ ] Sliding window
- [ ] Stacks
- [ ] Binary search
- [ ] Linked lists
- [ ] Trees
- [ ] Heaps
- [ ] Graphs
- [ ] Greedy and intervals
- [ ] Dynamic programming
